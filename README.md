## 编译与运行

在仓库根目录打开终端：

```powershell
gcc .\01-basics\hello-world.c -std=c17 -Wall -Wextra -o .\hello-world.exe
.\hello-world.exe
```

每个练习都应做到：自己先思考、独立编写、成功编译，并记录遇到的问题。
